### 🚀 What I'm Building & Architecting

* **[Festify](https://festify-sys.vercel.app)** — Digital Arts Festival Management SaaS built with Next.js 16 (Turbopack), React 19, TypeScript, and Supabase (PostgreSQL). Features an anti-bias "Blind Staging Invariant" stage evaluation system and a pure TypeScript multi-judge scoring engine with 80+ Vitest test suites.
* **[Scofist](https://scofist.com)** — Comprehensive Education Management System (EMS) serving 150+ active students across 9 RBAC roles. Features an AI assistant powered by Vercel AI SDK & Google Gemini with Zod-validated function calling, Next.js Edge Middleware JWT auth, and high-throughput virtualized data tables.
